## 📖 Description

This desktop application was developed specifically for the needs of an **Engineering Thesis** at the **Cracow University of Technology**. It serves as a specialized tool for the spatial analysis, processing, and visualization of geophysical anomalies.

The software allows for the identification of patterns and irregularities in spatial data, providing geoinformatics students and professionals with a robust environment for interpreting geophysical measurements.

## ✨ Features

### 🔍 Analysis & Processing
* **Anomalies Detection**: Specialized algorithms to identify spatial deviations in geophysical datasets.
* **Spatial Interpolation**: Advanced mapping of discrete measurement points into continuous surfaces.
* **Filtering & Cleaning**: Tools to reduce measurement noise and improve data quality for analysis.

### 📊 Visualization
* **2D/3D Mapping**: Generation of interactive heatmaps and 3D surface models of anomalies.
* **Profile Analysis**: Creation of cross-sectional views to analyze anomalies along specific transects.
* **Dynamic Scaling**: Adjustable color scales and contour intervals for better data interpretation.

### 📁 Data Management
* **Import/Export**: Support for common geophysical data formats and coordinate systems.
* **Coordinate Transformation**: Handling spatial data within the context of geoinformatic standards.

## 🚀 Getting Started

### Prerequisites
* Python 3.9 or higher.
* Recommended: Virtual environment (venv).

### Installation
1.  **Clone the repository**:
    ```bash
    git clone [https://github.com/mesniezek/Geophysics-Anomaly-Sniezko.git](https://github.com/mesniezek/Geophysics-Anomaly-Sniezko.git)
    cd Geophysics-Anomaly-Sniezko
    ```

2.  **Install dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

3.  **Run the application**:
    ```bash
    python main.py
    ```
